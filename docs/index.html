TaskPilot docs

React project workflow MVP for portfolio and product iteration.

TaskPilot demonstrates a compact project workflow with a dashboard Home, dedicated Workspace, Kanban movement, compact collapsible cards, keyboard task movement, CRUD administration, editable checklists, objective completion signals, sidebar navigation, JSON backup import/export, filters, operational metrics, secondary priority queue, saved preferences, and guarded local persistence. The MVP is frontend-only so it can be reviewed quickly before backend or AI features are added.

Current MVP

React + Vite board with project/activity grouping, dashboard Home, dedicated Workspace, compact Kanban controls, paginated CRUD management, column filters, sortable administration tables, objective completion status, guarded browser storage, editable checklist drawer, saved preferences, and responsive layout.

Future Direction

Backend sync, user accounts, project spaces, AI planning, weekly reports, and integrations.
