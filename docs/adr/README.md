# Architecture Decision Records

Architecture Decision Records capture decisions that are difficult to infer from code alone.

## Status Values

- Proposed: under discussion.
- Accepted: current direction.
- Superseded: replaced by a later ADR.
- Deprecated: retained only for compatibility.

## Index

- [ADR-0001: Frontend-only JSON persistence](0001-frontend-json-persistence.md)
- [ADR-0002: Operational record visibility](0002-operational-record-visibility.md)

New records use the next four-digit number and include context, decision, consequences, status, and date. Accepted ADRs are not rewritten to hide history; a new ADR supersedes them.
